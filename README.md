# Coach Tae — Quarterback Training Website

**Website:** https://coachtaeqb.com/

A web experience for quarterback training, session discovery, and family engagement.

## Project overview
The website gives athletes and parents a central place to learn about training and interact with Coach Tae's training business. The product direction includes session booking, athlete/family profiles, and coaching resources.

## Technical focus
- Responsive Next.js application.
- Sports training and service-business user experience.
- Scheduling, checkout, and account workflows where configured.
- Maintainable application structure and deployment practices.

## Run locally
```bash
npm ci
npm run dev
```

Check project configuration before enabling integrations. Keep real athlete information and provider credentials out of source control.
