# Reproducible gameplay acceptance — bounded engine evidence

The six `acceptanceScenarios` in `modules/qb-lab/live-engine/acceptance.ts` contain validated configuration, a seed and exact per-tick inputs. `runAcceptance` starts with `createEngine`/`snap` and advances the real engine without changing positions, ratings, assignments or outcomes during the rep. Each reference terminates through an actual engine event and is compared frame-for-frame against a second run. These examples are available in the live engine's reference selector; they are synthetic, unapproved teaching cases, not real athlete measurements or reviewed coaching answer keys.

`tests/domain/gameplay-acceptance.test.ts` has **12 passing tests**. Some tests cover more than one requested scenario. The number is a test count, not proof that all twelve requested football scenarios are complete. The two pursuit pictures, passing-7 crossing and saved-play projection are explicitly controlled-state checks, described below. Related protection/physics and coverage tests exercise the mechanisms independently; none establishes calibrated football realism.

## Reproduce and review

Run `npm test -- --run tests/domain/gameplay-acceptance.test.ts`. Open `/qb-lab/simulator/engine`, choose a reference and inspect its exact recorded rep. Use replay/timeline controls to compare the reported event with actual player positions. To make a new decision, load the reference setup and snap a new rep; its result may differ from the recorded inputs. A reference review is not recorded as the athlete completing a rep.

Coach Tae should review each limited responsibility and route distribution using `docs/QB-LAB-COACH-APPROVAL.md`. The current 2D renderer remains the source of visible gameplay; a rigged Three.js/React Three Fiber field would require additional reviewed assets, camera/touch controls, renderer synchronization, licensing and physical-device performance evidence. No 3D implementation or professional physics certification is claimed, and no decorative 3D dependency was introduced.
